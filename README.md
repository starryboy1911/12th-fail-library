# 12th Fail Library

A professional and responsive library website designed for **12th Fail Library, Karon, Ballia, Uttar Pradesh**.

## 📚 About the Project

This project is a modern library website created to showcase library facilities, membership information, pricing, location, timings, and seat booking.

The website is designed with a clean and responsive interface so that students can easily view library details and book a seat.

## ✨ Features

- 📖 Professional library landing page
- 💺 74 total seats
- ❄️ AC facility
- 💰 Membership fee: ₹400/month
- 🕕 Opening hours: 6:00 AM – 7:00 PM
- 📍 Location: Karon, Ballia, Uttar Pradesh
- 📱 Responsive design
- 💬 WhatsApp seat booking
- 📞 Contact information
- 💺 Interactive seat booking system
- 📱 Mobile-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was created as a portfolio project to demonstrate frontend web development skills and the ability to build a real-world business website.
